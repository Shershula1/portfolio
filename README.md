# Портфолио Дани Ретивых

Каталог из двух проектов. На карточке — снимок, название и год. Клик по карточке открывает сам проект.

- **Неосвещаемая комната** — снимок с лучами открывает сайт комнаты.
- **Evernote** — заметки в браузере. Вход и регистрация работают на этом устройстве, записи никуда не отправляются.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run dev -- --port 4317
```

Проверка оптики комнаты:

```bash
npx tsx --test src/lib/penrose.test.ts
```
